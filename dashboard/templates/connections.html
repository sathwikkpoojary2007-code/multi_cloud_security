How provider access works

This app connects using provider API credentials with the permissions you grant. It does not use or store cloud console website passwords. Create an API identity or token once in the provider’s account, then enter it here; scans and approved changes can run from this dashboard. Use the smallest permissions needed and rotate credentials regularly.

AWS: S3 read and bucket public-access write · Azure: Storage Account read/write · Meraki: dashboard API key with configuration write for remediation · Cloudflare: account/zone read and rulesets write.
