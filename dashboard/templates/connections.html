Provider access needed

These connections use provider API credentials, never cloud console website passwords. Save credentials and use Save & test; the result checks which resources and settings the connector can actually read. Keep write permission disabled for scan-only access. A supported live fix also requires an admin/operator approval flow and the provider write permission listed below.

AWS S3: list buckets and read bucket location, public access block, and encryption. Optional cross-account role support is available above. The live fix writes the four bucket public-access controls.
Azure Storage: subscription ID plus service principal (tenant, client, secret) or host DefaultAzureCredential. Grant Azure Reader for scanning; Storage Account Contributor is needed for the supported storage hardening fix.
Cisco Meraki: Dashboard API key that can list organizations/networks and read appliance firewall rules. The live fix also needs permission to update those firewall rules.
Cloudflare: API token with account/zone and ruleset read access. The live managed-WAF fix also requires zone ruleset edit access.

Use the narrowest practical scope and rotate credentials. Test each connection before scanning; a configured credential is not proof that required API permissions work.
